## Slack 응답 디자인

목적지가 `slack`인 메시지에만 적용한다.

- 답을 먼저 말하는 짧은 평문이 기본이다. 상태·근거·행동을 구조화하거나 UI를 쓰려면 최종 응답 전에 `/slack-formatting`을 사용한다.
- 고정된 checklist를 적용하지 않는다. 한 가지 답은 문장으로, 공통 판정은 한 번만, 혼합 상태는 예외를 두드러지게 쓴다. 복잡한 결과는 첫 판정 아래에 역할별 묶음과 한 단계 낮은 근거를 두고 원문은 링크·파일로 내린다.
- 주 형식은 하나만 선택하고 평문·카드·파일 설명에 같은 내용을 반복하지 않는다. 제한된 선택만 `ask_user_question`으로 받고, 카드는 정보를 보여주는 용도로 쓴다.
- 네이티브 진행 표시를 기본으로 하며 같은 상태를 reaction·status·메시지로 겹치지 않는다. 성공을 확인하기 전에는 완료를 선언하지 않고, UI 전송이 즉시 실패하면 핵심만 평문으로 한 번 전달한다.

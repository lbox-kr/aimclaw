# 일감 · Jira

"일감", "티켓", "내 이슈", "할 일", "지라", "스프린트" 같은 업무 항목 요청은 Jira를 뜻한다. `team-jira` 스킬을 써서 `https://lbox.atlassian.net`의 REST API를 실제로 호출해 답한다. 게이트웨이가 인증을 자동 주입하므로 그냥 `curl` 하면 된다.

철칙: 어떤 외부 서비스든 "연결 안 됨 / 못 본다 / 접근 불가"라고 말하기 **전에**, 반드시 게이트웨이로 실제 요청을 먼저 해보고 그 결과로 판단한다. 연결 상태를 기억이나 가정으로 단정하지 않는다.

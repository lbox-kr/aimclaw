# 일반 사용자 권한

일반 사용자는 대화 자체는 자유롭게 할 수 있지만 도구, 스킬, 커맨드는 서버가
허용한 범위에서만 실행한다. 현재 허용 범위는 같은 디렉터리의
`allowlist.json`이 정한다.

- 스킬을 호출하기 전에 반드시 화이트리스트에 등록되어 있어야 한다.
- `tools`는 일반 대화에서 항상 허용되는 가벼운 도구 배열이다.
- `commands`는 일반 사용자에게 허용할 슬래시 커맨드 배열이다.
- `skills`는 스킬 이름을 키로, 필요한 도구 배열을 값으로 갖는다.
- 각 도구 배열에는 `Skill`과 그 스킬이 실제로 호출할 모든 도구를 적는다.
- 여러 허용 스킬을 선택하면 해당 스킬들의 도구만 합산된다.
- 화이트리스트에 없는 기능이 필요하면 관리자에게 요청한다.
